**SunPower Energy** is a high-converting, visually stunning frontend web application for smart rooftop solar installations, founded by **Naresh Yadav**. Features an interactive 3D 360° rotating solar panel viewer, an advanced mathematical Solar ROI & PM Surya Ghar Subsidy Calculator, realistic AI-generated images, and a consultation booking engine.

> **Founder & CEO:** Naresh Yadav  
> **Tech Stack:** HTML5, CSS3 Clean Energy Design System, Vanilla JavaScript (ES6+), HTML5 Canvas 3D Rendering.

---

## 🌟 Key Features

- **☀️ Interactive 3D Solar Panel Viewer**: 360-degree mouse/touch drag rotation engine rendered natively on HTML5 Canvas. Includes live sun angle adjustments, panel tilt controls, and cell technology toggles (N-Type TOPCon vs PERC).
- **🧮 Mathematical Solar ROI & Subsidy Calculator**:
  - Inputs: Monthly Electricity Bill (₹), Rooftop Area Available (sq. ft), Electricity Tariff Rate (₹/kWh).
  - Calculations: Recommended System Capacity (kW), Daily & Annual Generation (kWh), Gross Cost, PM Surya Ghar Govt. Subsidy Benefit (up to ₹78,000), Net Out-of-pocket Cost, Payback Period (Years), 25-Year Cumulative Net Savings, and CO₂ & Trees Planted Environmental Impact!
- **📸 Realistic AI Assets**: High-definition solar rooftop villa and smart hybrid inverter & lithium battery storage images.
- **💼 Founder Section**: Profile and company vision of **Naresh Yadav**.
- **📋 Lead Booking & Quote Modal**: Instant consultation booking form with auto-calculated system quote export.

## 🚀 How to Run Locally

Open `index.html` directly in any modern browser, or serve via HTTP server:

```bash
# Using Node.js http-server
npx http-server . -p 8085

# Or Python built-in server
python -m http.server 8085
```

Navigate to: `http://localhost:8085`
